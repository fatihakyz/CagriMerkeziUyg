# Katkıda Bulunma Rehberi

Çağrı Merkezi Uygulaması'na katkıda bulunmak istediğiniz için teşekkür ederiz! 

## 🚀 Nasıl Katkıda Bulunabilirsiniz?

### 1. Issue Bildirimi
- Hata bulduysanız detaylı bir issue açın
- Yeni özellik önerilerinizi paylaşın
- Dokümantasyon iyileştirmeleri önerin

### 2. Pull Request Süreci

1. **Fork ve Clone**
   ```bash
   git clone https://github.com/[sizin-kullanici-adiniz]/CagriMerkeziUyg.git
   ```

2. **Branch Oluşturun**
   ```bash
   git checkout -b feature/yeni-ozellik
   ```

3. **Değişikliklerinizi Yapın**
   - Temiz ve okunabilir kod yazın
   - Türkçe yorum ve değişken isimleri kullanın
   - Mevcut kod stiline uyun

4. **Commit Edin**
   ```bash
   git commit -m "feat: yeni özellik eklendi"
   ```

5. **Push Edin**
   ```bash
   git push origin feature/yeni-ozellik
   ```

6. **Pull Request Açın**
   - Değişikliklerinizi detaylı açıklayın
   - Varsa ekran görüntüleri ekleyin

## 📝 Commit Mesajı Formatı

- `feat:` - Yeni özellik
- `fix:` - Hata düzeltme
- `docs:` - Dokümantasyon değişikliği
- `style:` - Kod formatı değişikliği
- `refactor:` - Kod iyileştirme
- `test:` - Test ekleme/düzeltme
- `chore:` - Genel bakım işleri

## 🎯 Kod Standartları

- C# kodlama standartlarına uyun
- Anlamlı değişken ve metod isimleri kullanın
- Karmaşık kod bloklarına yorum ekleyin
- Türkçe isimlendirme kullanın (proje dili Türkçe)

## ✅ Pull Request Kontrol Listesi

- [ ] Kod derlenebiliyor mu?
- [ ] Değişiklikler test edildi mi?
- [ ] README güncellenmeleri yapıldı mı (gerekiyorsa)?
- [ ] Commit mesajları anlamlı mı?

## 🤔 Sorularınız mı Var?

Issue açarak sorularınızı sorabilirsiniz. Memnuniyetle yardımcı oluruz!

## 📜 Lisans

Katkıda bulunarak, katkılarınızın MIT Lisansı altında lisanslanmasını kabul etmiş olursunuz.
